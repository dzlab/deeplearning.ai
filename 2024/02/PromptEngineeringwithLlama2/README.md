# Prompt Engineering with Llama 2


![Prompt Engineering with Llama 2 promotional banner](https://info.deeplearning.ai/hs-fs/hubfs/V2_DeepLearning_Meta_Llama_2_Banner_2070x1080.png)

Dear learner, 

 

We’re pleased to announce the launch of our new short course [Prompt Engineering with Llama 2](https://www.deeplearning.ai/short-courses/prompt-engineering-with-llama-2/), built in collaboration with Meta.

 

This course is designed to help you advance your prompt engineering skills. You’ll learn best practices in prompting and building applications with the collection of Llama 2 models.

 

Llama 2 models and model weights are free to download, including quantized model versions that can run on your local machine. You’ll interact with these models with a simple API call and explore the differences in output between models for various tasks.

![Prompt Engineering with Llama 2 GIF](https://info.deeplearning.ai/hs-fs/hubfs/Launch%20email%20GIFs%20(1).gif)

What you’ll do in this course: 

  -  Learn best practices for prompting and selecting among the Llama 2 models by using them as a personal assistant to help you complete day-to-day tasks.
  -  Experiment with advanced prompt engineering techniques, like few-shot prompting to get Llama 2 to classify the sentiment of text messages, and chain-of-thought prompting to solve logic problems.
  -  Treat Code Llama as a pair programming partner to learn to write and improve code.
  -  Promote safe and responsible use of LLMs by having Llama Guard check user prompts and model responses for harmful content.

Join a growing community of open source developers that is building applications powered by Llama 2.

Learn best practices for prompting and selecting among Meta Llama 2 models.

- Learn best practices specific to prompting Llama 2 models.
- Interact with Meta Llama 2 Chat, Code Llama, and Llama Guard models.
- See how you can build safe, responsible AI applications using the Llama Guard model.
