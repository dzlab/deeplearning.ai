Dear learner, 

 

Sharing our latest short course with you: [Building and Evaluating Data Agents](https://www.deeplearning.ai/short-courses/building-and-evaluating-data-agents/), created in collaboration with Snowflake and taught by Anupam Datta (AI Research Lead) and Josh Reini (Developer Advocate).

 

A data agent is an agent that extracts data from sources such as files, databases, or web pages, analyzes the extracted data, and provides insights and visualizes its findings. But most data agents struggle with reliability, they give inconsistent answers or can't handle multi-step reasoning. 

 

In this course, you'll learn to build data agents that get better over time through systematic evaluation.

You'll learn to:

  -  Build a multi-agent workflow with specialized sub-agents for different data sources
  -  Evaluate both the agent's final output and its reasoning process
  -  Add runtime evaluations that help the agent self-correct mid-task
  -  Use the Goal-Plan-Action (GPA) framework to measure and improve performance
  -  Connect to Snowflake's Cortex for structured and unstructured data retrieval

You'll build a complete data agent system that plans its approach, connects to databases and files, performs web searches, and provides insights, all while evaluating and improving its own performance.
