# ACP: Agent Communication Protocol

![V5_DeepLearning_IBM_ACP_Banner_2070x1080](https://info.deeplearning.ai/hs-fs/hubfs/V5_DeepLearning_IBM_ACP_Banner_2070x1080.png)

Dear learner, 

 

We’ve partnered with IBM Research’s BeeAI to bring you a new short course:

[ACP: Agent Communication Protocol](https://www.deeplearning.ai/short-courses/acp-agent-communication-protocol/), taught by Sandi Besen and Nicholas Renotte.

 

Building a multi-agent system with agents shared across teams and organizations can be challenging. You may need to write custom integrations every time a team updates an agent or changes frameworks.

 

The Agent Communication Protocol (ACP) solves this by providing a shared standardized interface for agent collaboration, so you can integrate and reuse agents regardless of how they were built.

![Launch email GIFs (90)](https://info.deeplearning.ai/hs-fs/hubfs/Launch%20email%20GIFs%20(90).gif)

In this hands-on course, you’ll:

  -  Wrap a RAG agent in an ACP server and call it from an ACP client
  -  Connect agents across different frameworks, including one built with CrewAI and Smolagents
  -  Chain ACP-compliant agents in a sequential flow to handle multi-step tasks
  -  Build a hierarchical workflow using a router agent that transforms a user’s query into tasks and delegates the tasks to agents available through ACP servers
  -  Combine ACP with MCP to enable both agent-to-agent communication and tool use
  -  Publish your agents to BeeAI’s open-source registry to make them discoverable and reusable across teams

By the end, you’ll know how to build ACP-compliant agents that can work together to solve tasks without needing to refactor your system.
