# AI Code Review

![New Course: AI Code Review.](https://info.deeplearning.ai/hs-fs/hubfs/Qodo_EndCard_01%20(1).png)

Dear learner, 

 

AI can write more code than any team can review by hand, and a pull request can look perfectly reasonable while missing a requirement or hiding a security issue.


In our new short course, [AI Code Review](https://www.deeplearning.ai/courses/ai-code-review), built in collaboration with Qodo and taught by Nnenna Ndukwe, you'll learn the practices that make AI code review effective, then build your own review agent to understand how these systems work under the hood. The quality of a review depends more on the context the reviewer has than on the model behind it and you'll learn to provide both.


In this course, you'll learn how to: 

  -  Run an AI review before opening a pull request, using a reviewer that didn't write the code

  -  Give the reviewer task and repository context so it catches missed requirements and pattern violations

  -  Triage findings by risk, and turn good feedback into reusable standards

  -  Build a context engine with chunking, embeddings, and vector search

  -  Combine specialized agents, like a security expert and a codebase-pattern expert, into a reviewer that outperforms a single general one
