# [Building Adaptive AI Agents](http://deeplearning.ai/courses/building-adaptive-ai-agents)

![New AI course by Oracle and DeepLearning.AI focuses on building adaptive coding agents that learn from experience.](https://info.deeplearning.ai/hs-fs/hubfs/Oracle_EndCard_01.png)

 

Dear learner, 

 

An agent that spent several minutes fixing an environment issue yesterday will burn the same time and tokens rediscovering the fix today. Every fresh session starts from zero.


In our new short course, [Building Adaptive AI Agents](http://deeplearning.ai/courses/building-adaptive-ai-agents), built in partnership with Oracle and taught by Nacho Martínez and Casius Lee, you'll build a coding agent that carries experience forward and gets better with every run.


In this course, you'll learn how to:

  -  Turn an agent's traces, its conversations, tool calls, errors, and fixes, into reusable skills, with a human approving each one

  -  Build a code knowledge graph from imports, function calls, and co-edits in git history

  -  See where graph-based retrieval beats keyword and regex search in large codebases

  -  Decide when adapting the model itself, with techniques like fine-tuning, is the right tool
